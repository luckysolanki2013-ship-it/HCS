# HCS Enterprise Website — Next.js Production Frontend

This is the next-step HCS build: a Next.js App Router frontend with an enterprise consulting-site information architecture and a TCS-inspired visual/UX direction, while retaining HCS-specific identity and source-derived content.

## Included
- Next.js + TypeScript
- Responsive enterprise header and mega menus
- Home, Services, Industries, Solutions, About, Insights, Careers, Contact
- Scroll reveal animation
- HCS logo and supplied service-brochure imagery
- SEO metadata foundation
- Contact form UI ready for CRM/API integration

## Run locally
1. Install Node.js 20+.
2. Open this folder in terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Production
- Deploy directly to Vercel, or any Node.js-compatible host.
- Connect `ContactForm.tsx` to your CRM/API before launch.
- Add Google Analytics/Search Console, sitemap, robots.txt, legal pages and final approved copy.
- Verify all client names, pricing, claims and case studies before publication.

## Design direction
The architecture intentionally follows the enterprise pattern of large consulting/technology sites: Industries, Services, Solutions, Insights, Careers, Contact, editorial hero, mega navigation, customer-value storytelling and strong CTA sections. It does not copy TCS proprietary text, images or branding.
